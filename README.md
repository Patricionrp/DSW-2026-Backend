# TP-Backend — DSW 2026

API REST del Trabajo Práctico de Desarrollo de Software. Sistema de reserva de espacios.

## Stack

- Node.js + TypeScript (ESM)
- Express
- MikroORM + MySQL (a integrar en una etapa posterior)

## Requisitos previos

- [Node.js](https://nodejs.org/) 20 o superior (se desarrolló y probó con Node v22).
- npm (viene incluido con Node).

## Instalación

Clonar el repositorio e instalar las dependencias:

- git clone https://github.com/Patricionrp/DSW-2026-Backend.git
- cd DSW-2026-Backend
- npm install

## Scripts disponibles

npm run start:dev -> inicia la aplicación escuchando en `http://localhost:3000/`.
